## Method and limitations

Read the task, docs/CONTEXT.md, docs/ARCHITECTURE.md and existing discovery helpers. Used bounded plain HTTP and one serial Playwright browser process at a time, following official links and capturing jobs requests. Browser capture recorded actual request method, body and response; it is not a later cookie-free replay. Sanitized evidence retains only public job fields in codex_20260909_group_de_evidence.json. CSV `api_url` follows the task's overloaded convention: for custom/Comeet rows it can be the verified HTML board, not a JSON API.

Further adapter-source inspection was prevented by filesystem access denial; automatic escalation review then rejected the read because the account usage limit had been reached. Therefore existing scraper execution compatibility is explicitly untested. No unsupported ATS adapter was written. Empty results remain unresolved with blank api_url as requested.

## Unsupported ATS

**D-ID — solved, Workable.** [Official page](https://www.d-id.com/careers/) contains two real Workable posting links; following one redirects to tenant `d-id`. [Board](https://apply.workable.com/d-id/) actually calls **POST** `https://apply.workable.com/api/v3/accounts/d-id/jobs`, HTTP 200, JSON body `{"query":"","department":[],"location":[],"workplace":[],"worktype":[]}`. Envelope `{total:2, results:[...]}`; two returned titles: AI Researcher - Video Generation; Bookkeeper & Payroll Specialist. Both locations are Tel Aviv-Yafo, Israel. The same two roles are present on the employer page. No pagination token occurred in this response.

**AccessFintech — solved, Workable.** [Board](https://apply.workable.com/accessfintech/) calls **POST** `https://apply.workable.com/api/v3/accounts/accessfintech/jobs`, HTTP 200, with the same body. Envelope `{total:3,results:[...]}`. All three titles: NOC Student; Security Operations & GRC Manager; Project Manager. First is Tel Aviv; second includes Glasgow, London and Tel Aviv-Yafo in `locations`; third London. Do not use only the primary `location` for multi-location roles. No pagination token occurred in this response.

Workable result fields personally observed: numeric `id`, `shortcode`, `title`, `location`, `locations`, `state`, `isInternal`, `published`, `department`, `workplace`, optional `type`. List results do not supply full descriptions or a URL field. Actual board anchors use `/tenant/j/shortcode/` and the observed shortcodes match the API. New adapter required; do not route this to an existing mapping. These small responses do not prove pagination behavior for large Workable accounts.

## Recovered careers pages

**Matrix IT — solved, custom HTML.** [Official all-jobs page](https://www.matrix.co.il/jobs/tag/all-jobs/) returned HTTP 200 and contains **506** `h2.job-title a` matches with **506 distinct href strings**. Real samples: מהנדס/ת בדיקות מנוסה; למטריקס (צפון) דרוש/ה ראש צוות DevOps; למטריקס (קריות) דרוש/ה איש/ת סיסטם. Every match isolates the posting title and actual detail link. Some titles repeat with different URLs, so distinct href count is not a claim of unique requisitions. Static HTML extraction verified; production browser adapter not run. The selector contains title/link only, so location/content enrichment would need the enclosing card or detail page. No additional pagination was proven necessary or tested.

**Simply — solved, custom HTML.** [Official careers page](https://www.hellosimply.com/careers) returned HTTP 200 with **6** individual `a.PositionsSection_jobLink__D56G_` anchors, each containing `h3.item-title` and a real `/careers/<UUID>` href. Titles include Video Creative Lead; Data Lead; Legal Counsel; Influencer Project Manager; Senior AI Research Engineer; Senior Software Engineer. No known ATS host was present in the examined page. Selector is not a department wrapper. CSS-module hash is build-sensitive. Static extraction verified; browser adapter and detail enrichment untested.

**Malam Team — blocked.** Recovered [official careers page](https://www.malamteam.com/לובי-קריירה/), also linked from the [official homepage](https://www.malamteam.com/) in primary search. HTTP returned 403 and browser remained on Cloudflare security verification. Indexed job text was not promoted to live verification. No API or selector reported.

**Dream Security — solved board, Comeet.** [Official careers page](https://www.dreamgroup.com/careers) was found in primary search but returned 404 both HTTP and browser. Primary search also exposes company-owned job pages, e.g. [SRE On-Prem](https://www.dreamgroup.com/comeet-positions/site-reliability-engineer-sre-on-prem-c9e64), identifying Dream's sovereign AI business. A separately discovered [Comeet Dream board](https://www.comeet.com/jobs/dreamgroup/99.002) loaded and rendered **31 real posting links**, excluding board-home and cookie-policy anchors. Samples: Site Reliability Engineer (SRE) On-Prem; Solution Architect; Threat Research - Solution Team. Locations include Tel Aviv and TLV - ISR. The verified URL is the HTML board, not a newly identified JSON endpoint. Existing plain-HTTP `scrape_comeet` compatibility and inline-data extraction have not been run; treat this as a verified source requiring integration validation. No inference of zero vacancies from the broken official landing page.
